# Nicolas-Cage-movies---SQL-Analysis
This is a beginner SQL practice project using a guided Nicolas Cage movie dataset.
The goal is to practice SQL queries beginner to intermediate using structured data.

DATASET :
The nicolas_cage_movies table includes
Movie title and release Year 
Genre and director
Budget and box office revenue
Rotten tomatoes score 
Oscar nomination
Release Decade

SQL SKILLS:-
SELECT ,FROM , WHERE
SELECT DISTINCT
AS
AND OR NOT
GROUP BY
ORDER BY 
AGGREGATES

Project Progress:-
First SELECT query completed 
Filter movies by release year 
Filter movies using multiple conditions
Sort and explore move data
Develop independent analysis questions 

Learning Goals:-
I am building my sql skills by writing, testing and documenting queries.
A total of 37 queries has been answered here.
